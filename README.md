# 图谱框架 · 关系图编辑器（本地）

一个**独立的小工具**：专门用来画"关系图 / 框架图"——把想法、模块、任务画成节点，用连线表达依赖或流程，
图谱存成本机 JSON，随时新建、切换、导入导出。桌面双击「**图谱框架**」快捷方式即可打开。

装在你要的位置：`D:\AI驱动盘\Deepseek\git kuangjia`

```
D:\AI驱动盘\Deepseek\git kuangjia\
  start-graph.vbs        ← 快捷方式真正启动的东西：后台起服务 + 打开页面（不弹黑窗）
  start-graph.cmd        ← 同上，带控制台窗口，出问题用它看日志
  app\index.html         ← 编辑器本体（单文件，HTML+CSS+JS，无依赖、无构建）
  app\server.mjs         ← 本地服务：送页面 + 把图谱存进 graphs\
  graphs\                ← 你的图谱都在这（一个框架一个 .json，可直接手改/进 git）
  assets\graph.ico       ← 桌面快捷方式图标（由 tools\make-icon.mjs 生成）
  tools\install.ps1      ← 装/刷新：生成图标 + 建桌面快捷方式（幂等）
  tools\smoke.mjs        ← 自检：脚本编译 + 纯逻辑 + 真起服务跑 HTTP 接口
  tools\relocate-to-deepseek.ps1  ← 当初用它把这个工具搬进来（已用不上，留作参考）
```

## 用法

- **双击桌面「图谱框架」**：打开编辑器（本地服务在 `http://127.0.0.1:43110/`，只在回环地址监听）。
- **新建时可以选框架**：点 `新建` 弹出「新建框架 · 选一个起点」，挑一个模板就有现成骨架，
  也可以选「空白」从零画。当前内置 8 个：

  | 模板 | 内容 |
  |---|---|
  | 空白 | 什么都不放 |
  | 项目流程 | 需求 → 设计 → 实现 → 验证 → 交付 |
  | 系统架构 | 用户入口 / 前端 / 服务接口 / 数据存储 / 日志监控 / 配置中心 |
  | 职责分工 | 总负责 → 模块 A/B/C → 协作方 |
  | 决策树 | 问题 → 条件分支（是/否）→ 方案 |
  | 里程碑 | 起点 → 里程碑 1/2/3 |
  | 问题排查 | 现象 → 假设 → 验证 → 结论/修复（+复现步骤） |
  | 方案对比 | 目标 → 方案 A/B/C → 结论 |

- 顶部下拉可以**在已有的多个框架之间切换**（`新建 / 重命名 / 删除 / 导入 / 导出`）；`撤销 / 重做` 有 80 步历史。
- **点一个节点**：右侧面板显示它的标题、说明标签，以及**4 个颜色块**，点一下即换色
  （蓝 `#4c6ef5` / 绿 `#12b886` / 橙 `#e0a03a` / 紫 `#a855f7`），当前颜色会高亮。
- **多选一起动**：`Shift`（或 `Ctrl`）**+ 点**可以加选/取消节点，被选中的节点
  **拖动时一起走、换色一起换、删除一起删**（`Delete` 或右侧「删除这 N 个节点」）。
- **间距滑杆（重排旁边）**：`间距 80~420`，**边拖边看**——距离实时改变，不用点一下等一次。
  - 没选节点 = 调**整张图**的间距；**选中 ≥2 个节点 = 只调它们之间的距离**，其他节点不动。
  - 滑杆的值会记住；`重排` 会按当前间距重新力导向排版。
  - 布局已做**尺度归一化**：连点多少次「重排」都停在同一个间距，不会再越点越挤。
- **右侧可拖宽**：把画布和右栏之间那条竖线往左/右拖即可（`200~640px`），**双击复位**，宽度会记住。
- 画图手势：
  - **连线（正常方式）：左键点节点 A → 再左键点节点 B** 就连上了（起点会高亮；再点自己或按 `Esc`、点空白取消）
  - **右键**专门给菜单：
    - 右键**节点**：连线到…（再左键点目标）/ 重命名 / 复制这个节点 / 删除节点
    - 右键**空白**：在此新建节点 / 粘贴 / 适应 / 重排 / 网格 / 导出 JSON·SVG·PNG
    - 右键**连线**：改连线标签 / 删除连线（双击连线也能直接改标签）
  - **双击空白** = 在此新建节点（或用 `＋节点` / 快捷键 `N`）
  - **拖动节点** = 移动（开网格后自动吸附到 25px 格）；**双击节点** = 改标题
  - **拖动空白** = 平移；**滚轮** = 以指针为中心缩放；顶栏 `−/＋` 按钮也能缩放
  - **点连线** = 选中，再点 = 删除；选中后 `Delete` = 删除节点或连线
  - 侧栏「从这里连线」是第三种连线入口（选中节点 → 点它 → 再点目标）
  - `Ctrl+C / Ctrl+V` 复制粘贴节点（连同它内部的连线）· 搜索框输入即高亮，回车把视图居中到匹配节点
  - `N` 新建 · `L` 重排（力导向）· `F` 适应窗口 · `G` 网格吸附 · `Esc` 取消连线/取消选中
- **导出**：`导出`=JSON（可再导入）· `SVG`=矢量图（进浏览器/Office/再次编辑）· `PNG`=2 倍图（发文档/聊天用）
- 编辑后**自动保存**（约 0.7 秒防抖）到 `graphs\<框架名>.json`；文件是普通 JSON，想手改或纳入 git 都行。

> 手势与功能参考了同类工具：Obsidian 图谱视图的节点/连线/搜索过滤、
> draw.io 与 Excalidraw 的边标签与导出、Canvas 的分组画布思路。

## 这个目录的权限（重要）

`D:\AI驱动盘\Deepseek` 是 Node 安装目录树，原本**只给普通用户读权限**（写会被拒绝）。
搬进来时用管理员权限做了一次授权（`icacls <目录> /grant <用户>:(OI)(CI)M`），
所以现在 `graphs\` 里可以正常读写。**如果哪天又变成只读**（比如重装 Node 覆盖了 ACL），
用管理员 PowerShell 跑一次：

```powershell
icacls "D:\AI驱动盘\Deepseek\git kuangjia" /grant "$env:USERNAME:(OI)(CI)M"
powershell -ExecutionPolicy Bypass -File "D:\AI驱动盘\Deepseek\git kuangjia\tools\install.ps1"
```

## 节点说明 = 一枚「标签」（写了才显示）

- 选中节点 → 右侧 **说明标签** 里写一句话，**节点下方立刻多出一枚小标签**（圆角胶囊 + 小圆点）。
- **留空就不显示**：不写就没有那枚标签，节点保持干净；清空即消失。
- 太长会自动截断（14 字 + …），宽度有上限，不会把图撑乱。
- **新建节点后就能直接写**：新建时会选中「标题」，**按 Enter 跳到「说明标签」**，写完再按 Enter 收工
  （Shift+Enter 换行）。
- 导出 **SVG / PNG 也带这枚标签**；模板自带的说明（比如项目流程的「拆模块与接口」）同样会显示成标签。

## 右侧面板

- 顺序是「**选中的节点**」在上、「**我建过的框架**」在下，所以写标题/说明不用往下翻。
- **我建过的框架**（可伸缩）：标题右边有个小三角和框架数量，**点标题展开 / 再点收起**，状态会记住。
  - 列出 `graphs\` 里所有框架（按名字排序），每条显示 `n 节点 · m 边 · 日期`
  - **单击** = 显示**预览**（缩略图 + 节点/连线数），预览右上角 **✕ 可关闭**，不会再一直占地方；
    点「打开这个框架」后预览也会自动收起；**双击**某条 = 直接打开
  - 正在编辑的那张会高亮
- **选中的节点**：标题 / **说明标签**（见上）/ **4 个颜色块**（点一下即换）/ 从这里连线 / 复制 / 删除节点
- 选中连线时显示标签输入框与「删除连线」

## 自检 / 重装图标与快捷方式

```powershell
cd "D:\AI驱动盘\Deepseek\git kuangjia"
node tools\smoke.mjs                    # 纯逻辑 + HTTP 接口 + 导出完整性；期望最后一行「全部通过」
node tools\ui-test.mjs                  # 真浏览器（Edge 无头 + 真鼠标事件）跑：建节点/拖动/连线/换色/右侧预览
powershell -File tools\install.ps1      # 幂等；重建图标与桌面快捷方式
```

`ui-test.mjs` 用 `KG_GRAPHS` 把服务指到临时目录，**不会动 `graphs\` 里的真实框架**。
它会捕获页面异常原文——之前那个"界面像死了"的 bug（漏导出 `KG.clip`，每次重绘都抛异常）
就是它抓出来的，现在已经加了静态防线：`smoke.mjs` 会检查页面用到的每个 `KG.xxx` 都已导出。

## 已知边界

- 只监听 `127.0.0.1`，不对外；没有账号体系，本机谁都能看（图谱就是本机文件）。
- 图谱存在浏览器外的 JSON 里，因此不吃浏览器缓存；换浏览器/清缓存都不影响。
- 页面本身不联网，除本地服务外没有任何请求。
